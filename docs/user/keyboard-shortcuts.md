# Keyboard shortcuts

Help > Keyboard shortcuts (F1) opens this list in the program. The window shows the names this computer uses (Ctrl, or Cmd on macOS). A box at the top narrows it: typing matches the keys and the words. Escape closes the window.

Mouse gestures are listed after the keys of each group.

## Files and projects

| Keys | What it does |
|---|---|
| Ctrl+O | Open a file |
| Ctrl+Shift+O | Open several files |
| Ctrl+Alt+O | Open a folder and list its files |
| Ctrl+W | Close the file the plot shows |
| Ctrl+Q | Quit |
| Drop files or a folder | List them, and show the first seismic file |

## Seismic plot

| Keys | What it does |
|---|---|
| Left / Right / Up / Down | Pan a tenth of the view, the way the key points |
| Shift+Left / Shift+Right / Shift+Up / Shift+Down | Pan a whole view |
| + / - | Zoom in or out about the pointer (keypad + and - do the same) |
| Ctrl+Up / Ctrl+Down | Zoom the up-down axis only |
| Ctrl+Left / Ctrl+Right | Zoom the across axis only |
| Ctrl+0 | Fit the whole record (keypad 0 does the same) |
| ] / [ | More or less gain, 3 dB; with Shift, 12 dB (keypad * and / do the same) |
| Backspace | Back to the previous view |
| Alt+Left / Alt+Right | Select the previous or next trace (Alt+Up / Alt+Down when time is across) |
| Page Down / Page Up | Next or previous record |
| Home / End | First or last record |
| Ctrl+G | Go to a record number |
| P | Show the traces raw, or through the filters |
| Move the pointer | The trace under it is highlighted, and read out on the status bar |
| Left click | Select that trace |
| Ctrl + click | Add the trace to the selection, or take it out |
| Shift + click | Select from the trace clicked last to this one |
| Left drag | Pan |
| Middle drag | Pan |
| Right drag | Zoom to the box |
| Right-click | The menu of the trace under the pointer |
| Right-click the display header | Choose the header fields |
| Wheel | Zoom both axes about the pointer |
| Ctrl + wheel | Zoom the up-down axis only |
| Shift + wheel | Zoom the across axis only |
| Sideways wheel | Zoom the across axis only |
| Drag a scroll bar | Pan along that bar |
| Click a scroll bar's track | Pan by a whole view; held, it repeats |
| Wheel over a scroll bar | Pan along that bar |

## Selection and edits

| Keys | What it does |
|---|---|
| Ctrl+Z | Undo the last edit of the file shown |
| Ctrl+Shift+Z, Ctrl+Y | Redo the edit undone last |
| Ctrl+A | Select every trace the Seismic window shows |
| R | Reverse the polarity of the trace under the pointer, or put it back |
| K | Kill the trace under the pointer, or restore it |
| E | Exclude the trace under the pointer from the plot's filters, or put it back |
| F | Open the amplitude spectrum of the trace under the pointer |
| M | Select the trace's station on the map |
| Escape | Cancel the drag, or clear the selection |

## Spectrum and graphs

| Keys | What it does |
|---|---|
| Right-click a plot | Explain: what the plot shows and how to read it (Esc closes it) |
| Left / Right | Move the held cursor a bin, or a sample in a graph |
| Up / Down | Move the held cursor to another curve, or a frequency bin in a spectrogram |
| Home / End | Move the held cursor to the ends |
| Escape | Let the held cursor go |
| Alt+Left / Alt+Right | The previous or next trace of the record |
| Move the pointer | The cursor follows it; moving it lets a held cursor go |
| Wheel | Zoom the graph about the pointer |
| Drag | Pan the graph |
| Right drag | Zoom the graph to the box |
| Double-click | Fit the graph to its data |
| Click a legend entry | Hide that curve, or show it again |

## Map

| Keys | What it does |
|---|---|
| + / - | Zoom in or out about the pointer (keypad + and - do the same) |
| Left / Right / Up / Down | Pan a tenth of the view |
| Shift+Left / Shift+Right / Shift+Up / Shift+Down | Pan a whole view |
| Ctrl+0 | Fit the whole survey (keypad 0 does the same) |
| Backspace / Alt+Left | Back to the previous view |
| Escape | Cancel the drag, or end the ruler, or clear the selection |
| Move the pointer | The point under it is described, and its traces light up in the plot |
| Left click | Select the point, or show a source's record |
| Ctrl + click | Add the point to the selection, or take it out |
| Shift + click | Select the stations along the line to this point |
| Left drag | Pan |
| Middle drag | Pan |
| Ctrl + drag | Measure a line; its length is shown until Escape |
| Drag with the ruler on | Measure, as Ctrl + drag does |
| Shift + drag | Select the points in the box, and their traces |
| Ctrl+Shift + drag | Add the points in the box to the selection |
| Right drag | Zoom to the box |
| Right-click | The menu of the point under the pointer |
| Wheel | Zoom about the pointer |

## Tables

| Keys | What it does |
|---|---|
| Up / Down | The next or previous file or record (not in the filter box) |
| Page Down / Page Up | A page of rows on or back |
| Home / End | The first or last row |
| Tab / Shift+Tab | The next or previous control of the window |
| Enter / Space | Act on the control Tab reached |
| Ctrl+C | Copy the header value, or the row, that has the focus |
| Delete | Delete the selected reference in the Reference archive (it asks first) |
| F2 | Rename the selected reference in the Reference archive |
| Click a row | Show that file or record (when the window already had the focus) |
| Double-click a header row | Show that trace's record in the plot |
| Shift + click a header row | Select the traces from the row clicked last |
| Ctrl + click a header row | Add that trace to the selection, or take it out |
| Right-click a header row | Copy the row, or the rows read |

## Windows

| Keys | What it does |
|---|---|
| Ctrl+Shift+R | Put every window back as at a first start |
| F1 | Open this list |
| Escape | Close a dialog, or this list |
| Enter | Confirm the dialog (Reopen, Save layout) |
| Drag a window's title bar | Dock it onto another window |
| Right-click the status bar | Choose what the status bar reads out |
| Click a notice | Show the Jobs window |
| Click the tray icon | Its menu: Show viewSEG, Open file, Quit |
